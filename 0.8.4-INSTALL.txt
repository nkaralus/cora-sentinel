TO PICK UP THE UNIT CHANGE ON YOUR HOST: you run the venv install, not the .deb, so your unit is wherever you put it. Add the line
    RestartPreventExitStatus=2
under Restart=on-failure in it, then: sudo systemctl daemon-reload && sudo systemctl restart cora-sentinel
The daemon changes need only the restart. After it, the first journal line should read:
    [cora-sentinel] 0.8.4 starting with: --cgroup-root /sys/fs/cgroup/cora --nft --nflog --floor ...

The refusal checks arguments for $VAR, ${VAR}, $(cmd), $1, a backtick, or a quote mark stuck to a value. A "~" is not refused.
