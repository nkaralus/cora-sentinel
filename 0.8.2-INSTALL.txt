The pages are generated from the real argparse parsers, so an option cannot be added to the code and forgotten; tests/test_man.py fails
if an option has no description, if a subcommand in a hand-parsed tool's usage text or a CORA_* variable it reads is missing, or if a
page is not clean roff. It already found one real gap: CORA_NFT_NATIVE (read by cora-firewall and the daemon) was undocumented.
